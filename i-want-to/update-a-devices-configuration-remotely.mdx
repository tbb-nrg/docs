---
title: "Update a Device's Configuration Remotely"
---

Some level of remote updates via the NRG Cloud is in the process of being developed by Engineering. So far, code has struggled to work well for even the most basic of updates. As of May 1, 2025 forthcoming releases are planning to be able to allow some remote changes.

LOGR|met will be capable of remote firmware updates via the Cloud.

It is _not_ anticipated that remote firmware updates to SymPRO loggers will be feasible - neither now nor in the future.
