---
title: "Change the Logger for an Existing Cloud Site"
---

NRG Cloud is configured to allow loggers or lidars to be swapped in at a given site. Below are customer-friendly instructions for how to conduct this swap.

If new loggers have been added to NRG Cloud already and are showing up as new sites, use the steps in italics.  If not this is not the case, ignore those steps.

1. Set the End Date of the logger that has been taken offline
   1. Navigate to Timeline
   2. Click on yellow bar next to "Loggers" bar
   3. Edit end date to reflect last day the original logger was online
2. Navigate to "Site Configuration" \> "Add logger" button
3. Set the Start Date of the new logger (make sure it's after the end date  of the previous)
4. Import data via the big yellow "\+" in the bottom right of the Cloud map
5. Check to see that the unit has populated the additional data
